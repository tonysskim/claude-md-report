# EERN Automation Runbook

## Confirmed output conventions

- Write Korean report summaries in polite, concise securities-research-style `~하다` prose; do not use informal speech.
- Preserve conditions, dates, comparison bases, and numerical values.
- Use the order: conclusion, numerical evidence, mechanism, implication, then limitations.
- For important English expressions, include the English term in parentheses after the Korean expression.
- Use an English title and source, followed by five bullet points; omit the full stop at the end of each bullet.
- When EERN registration differs from the original publication date, show both dates so delayed registration is not misread as a new publication.

## Configuration still required

Record the following when the automation is configured:

- Purpose and completion condition
- Trigger, recurrence, and time zone
- Registered input sources and required credentials
- Processing and validation steps
- Current output path and file name
- Notification and quiet-state behaviour
- Failure handling and user decision points
- Files that must survive cleanup for the next run
