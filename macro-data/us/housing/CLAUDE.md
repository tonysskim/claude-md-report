# Registered U.S. Housing Data

- Use only the registered `ZILLOW_RESEARCH_DATA`, `FHFA_HPI_DATA`, and `NAHB_HMI_DATA` services unless the user approves another source.
- For Zillow, discover the current ZORI CSV on the official registered research page and preserve its geography and housing-type definition.
- For FHFA, prefer the smallest suitable master or focused HPI file and preserve index type, geography, frequency, adjustment status, and vintage.
- For NAHB, use only free HMI files linked from the official registered HMI page; do not attempt to access paid NAHB data.
- Record the source URL, release period or vintage, relevant definitions, and retrieval date.
