# International Monetary Fund SDMX 3.0 Data

- Read the separate `IMF_DATA_WEO`, `IMF_FISCAL_MONITOR`, `IMF_GOVERNMENT_FINANCE_STATISTICS`, `IMF_QUARTERLY_GOVERNMENT_FINANCE_STATISTICS`, and `IMF_GLOBAL_DEBT_DATABASE` definitions from `public_services` in the shared store's `config\providers.json`.
- Public GET requests to the registered SDMX 3.0 dataflows and structures were verified without an API Key. Do not request, invent, or store an IMF API Key for these public flows. Portal sign-in or a subscription key described by the Swagger contract may still apply to portal access or restricted dataflows; do not generalise the public-flow result to unregistered flows.
- Dot-source `scripts\Invoke-ImfSdmxRequest.ps1` and call `Invoke-ImfSdmxRequest -ServiceAlias <ALIAS>` for data requests. The helper restricts calls to registered IMF service aliases and dataflow IDs or vintage patterns, uses HTTPS GET on `api.imf.org`, applies conservative spacing and size limits, and can return SDMX-JSON or SDMX-CSV.
- Use the SDMX structure and availability endpoints through `scripts\Invoke-RegisteredKeylessDataRequest.ps1` when discovering dataflow versions, dimensional order, valid codes, and available periods. Read the current DSD and code lists before interpreting or translating raw codes.
- For WEO, use the stable `WEO` flow for current selective data and a dated `WEO_*_VINTAGE` flow or official full workbook for reproducible vintages. Preserve the selected vintage, units, scale, and estimates-start boundary; do not infer actual-versus-projection status from the year alone.
- For Fiscal Monitor country data, discover and use the newest official `FM_*_VINTAGE` dataflow. The stable `FM` flow exposed aggregate country groups at registration time. Fiscal Monitor does not expose every requested debt series in the verified flow, so use registered WEO debt indicators where appropriate and never silently substitute a different concept.
- Annual GFS is divided into `GFS_SOO`, `GFS_BS`, `GFS_COFOG`, `GFS_SFCP`, `GFS_SOEF`, and `GFS_SSUC`; select the accounting statement before querying. Keep QGFS separate from annual GFS and preserve all account, sector, transformation, unit, status, and frequency dimensions.
- For Global Debt Database results, preserve sector and instrument scope, percent-of-GDP versus currency units, source annotations, and vintage. Do not sum overlapping sector aggregates.
- For broad updates, retrieve only the required countries, indicators, and periods. Keep the raw SDMX extract, transform names and labels only downstream, and replace revisions by the complete dimensional key plus observation period. Run `scripts\Test-ImfSdmxData.ps1` for a small read-only connection check.
