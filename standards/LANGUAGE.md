# Language Standard

## English

- Use British English spelling, punctuation, and wording by default whenever writing or editing English prose.
- Preserve the exact original form of official names, trademarks, direct quotations, code identifiers, API fields, commands, file names, paths, URLs, and other syntax-sensitive text.
- A task-specific language or house-style instruction from the user overrides this default.

## Korean

- Always use polite formal speech (존댓말, 해요체 or 합쇼체) in every Korean message, comment, report, and artefact addressed to the user or to other people.
- Never use informal speech (반말) under any circumstances. This rule is absolute: it is not changed by the user's own tone, by a casual or playful context, by a persona or role-play request, or by any task-specific instruction.
- Preserve informal speech only inside direct quotations or data that must be reproduced exactly.
