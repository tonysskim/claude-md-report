사용 규칙

TEXT

본문은 #333333, 캡션은 #8A8A8A. 메인 색은 제목과 강조 숫자에만 쓰고 문장 전체에는 쓰지 않습니다.

CONTRAST

#540A19·#8A2436·#A94A58 위에는 흰 글자, #C98089 이하 밝은 톤 위에는 #141414을 올립니다.

PRINT

흑백 출력 시 메인 계열 700과 500이 붙어 보입니다. 표·차트에서는 두 단계 이상 떨어진 톤끼리 조합하세요.
